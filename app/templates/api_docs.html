API 调用文档

仅一个接口
验证卡密接口
POST /api/verify

请求与响应均为 JSON 格式。验证通过后将自动把该卡密标记为「已使用」，不可重复使用。本平台对外仅开放此一个接口。

# 请求示例 POST /api/verify HTTP/1.1 Host: your-domain.com Content-Type: application/json { "code": "KMS-XXXX-XXXX-XXXX-XXXX" }
请求参数
字段类型必填说明
code string 是 卡密编码（大小写不敏感）
响应字段
字段类型说明
validboolean是否验证通过
codestring卡密编码
type_namestring卡密类型名称（如：月卡）
statusstringnot_found 不存在 / expired 已过期 / used 已使用 / unused 验证通过
expires_atstring到期时间（YYYY-MM-DD HH:MM:SS，永久卡为空）
devicestring使用方设备信息（操作系统 · 浏览器 · 端型）
messagestring结果提示信息
返回示例
验证通过
HTTP/1.1 200 OK { "valid": true, "code": "KMS-XXXX-XXXX-XXXX-XXXX", "type_name": "月卡", "status": "unused", "message": "验证通过，卡密已激活", "expires_at": "2026-09-16 12:00:00", "device": "Windows · Chrome · 桌面端" }
已被使用
{ "valid": false, "code": "KMS-XXXX-XXXX-XXXX-XXXX", "type_name": "月卡", "status": "used", "message": "卡密已被使用" }
已过期
{ "valid": false, "code": "KMS-XXXX-XXXX-XXXX-XXXX", "type_name": "月卡", "status": "expired", "message": "卡密已过期", "expires_at": "2026-08-01 00:00:00" }
卡密不存在
{ "valid": false, "code": "KMS-XXXX-XXXX-XXXX-XXXX", "status": "not_found", "message": "卡密不存在" }
代码调用示例
Python
import requests resp = requests.post( "https://your-domain.com/api/verify", json={"code": "KMS-XXXX-XXXX-XXXX-XXXX"} ) data = resp.json() if data["valid"]: print("激活成功，类型：", data["type_name"]) else: print("激活失败：", data["message"])
curl
curl -X POST "https://your-domain.com/api/verify" \ -H "Content-Type: application/json" \ -d '{"code": "KMS-XXXX-XXXX-XXXX-XXXX"}'
JavaScript
fetch("https://your-domain.com/api/verify", { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ code: "KMS-XXXX-XXXX-XXXX-XXXX" }) }).then(r => r.json()).then(data => { console.log(data.valid ? "激活成功" : "激活失败：" + data.message); });
接入建议

建议在服务端调用验证接口，不要在前端暴露卡密。

验证接口同时完成「校验 + 激活」，无需额外步骤。

卡密激活后不可恢复，请确认业务成功后调用。

安全与限流

平台仅对外开放 /api/verify 一个接口，其余接口需登录后使用。

同一 IP 每分钟最多调用 20 次，超限将返回 429 Too Many Requests。

登录 / 注册每分钟每 IP 最多 10 次，防止暴力破解。

请求头无需携带密钥，验证通过即自动激活卡密。
